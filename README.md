# Telegram-бот «bro napomni»

Бот на Python (aiogram 3) для напоминаний. Напоминания хранятся в SQLite и
не пропадают при перезапуске.

## Возможности
- `/remind 10 купить хлеб` - напомнить через 10 минут
- `/list` - список активных напоминаний
- Кнопки под напоминанием: отложить на 5 / 10 / 30 минут, на 1 час,
  на своё время или отметить выполненным

## Технологии
Python 3.13, aiogram 3, SQLite, python-dotenv

## Запуск
1. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
2. Создайте бота у @BotFather и получите токен.
3. Создайте файл `pomnibot.env` рядом с `bot.py`:
   ```
   BOT_TOKEN="vash_token"
   ```
4. Запустите:
   ```
   python bot.py
   ```
